# Game assets

Everything in this directory is project-authored and safe to keep in a public repository.

- `sprites/synthetic_pixel_atlas.png` — deterministic 128×128 RGBA atlas generated by `tools/fixtures/generate_synthetic_assets.py`. It contains 16 32×32 frames and is labelled `SYNTHETIC_FIXTURE` in `game/data/animations.json`.
- No FFBE sprite, portrait, texture, audio, CPK, APK, or extracted archive is present.

Godot's generated `.import` files may be committed so import settings are reproducible. The engine cache in `.godot/` and imported binary copies in `.godot/imported/` are ignored.
