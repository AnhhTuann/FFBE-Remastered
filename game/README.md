# Godot project

This is the Phase 1 Godot 4.7.2-stable technical foundation and Character Viewer. It contains **synthetic fixtures only** (`SYNTHETIC_FIXTURE`) and no FFBE source assets or protected data.

## Requirements

- Godot `4.7.2-stable` (verified locally as `4.7.2.stable.arch_linux.ed1daf0bf`)
- Matching export templates if executables are to be exported

## Run

```bash
godot --headless --path game --import
godot --path game
```

Main scenes:

- `res://scenes/boot/boot.tscn` — service initialization
- `res://scenes/menu/main_menu.tscn` — menu
- `res://scenes/settings/settings.tscn` — settings persistence
- `res://scenes/viewer/character_viewer.tscn` — region-aware character and animation viewer

## Tests

```bash
godot --headless --path game --script res://tests/test_runner.gd
python3 -m unittest discover -s tests -v
```

The GDScript runner counts failures itself and exits `1` when any check fails. Script errors, `push_error()`, or a failed bare `assert()` do not change Godot's exit code by themselves. It also instantiates the viewer scene and exercises region filtering, clip switching, playback controls, and the missing-animation diagnostic.

The animation validator deliberately accepts repeated and non-monotonic frame IDs so hold/oscillation sequences are representable; it rejects out-of-atlas rectangles, non-positive dimensions or durations, invalid origins, and missing timing/loop data. See `docs/audit/animation-frame-validation-note.md`.

Detailed evidence lives in `docs/qa/test-report.md`, `docs/qa/visual-review.md`, and `docs/qa/export-report.md`.

## Structure

```text
game/
  assets/sprites/       deterministic synthetic pixel atlas
  core/                 repository, identity, validation and save services
  data/                 versioned synthetic JSON content fixtures
  scenes/               boot, menu, settings and viewer scenes
  tests/                headless SceneTree runner
  project.godot         pinned project settings
  export_presets.cfg    Windows and Linux desktop presets
```

## Design boundaries

- `ContentRepository` is the only runtime entry point for normalized content.
- `UnitRecord` and `ContentId` are immutable typed domain views.
- `AnimationValidator` checks rectangle bounds, timing, offsets, origins, loop flags, and frame IDs before playback.
- `SaveManager` writes versioned JSON under `user://` with temp files, backups, migration, and corruption fallback. It stores no gameplay progression, inventory, or battle state.
- UI scenes communicate through Godot signals and do not read raw source files.
